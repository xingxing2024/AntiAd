# 配置详解

`plugins/AntiAd/config.yml` 全部配置项。改完执行 `/antiad reload` 生效（`storage.file`、`ai.max-concurrent` 需要重启）。

## settings：范围与开关

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `check-chat` | bool | `true` | 总开关。`false` 时聊天、`/me`、告示牌、铁砧、书与笔全部不检查 |
| `check-numeric-ip` | bool | `true` | 是否检测**十进制数字 IP**（`3107365173` → `185.54.161.53`）。8 位且像日期（`20261012`）不算 |
| `new-player-minutes` | int | `30` | **强制管制期**：首次进服后这么多分钟内一律检查（0 = 不强制，直接按老玩家判定） |
| `checked-commands` | list | `[me]` | 一并检查这些广播类命令（不含斜杠、小写）。`/msg`、聊天插件的频道指令等要覆盖就加进来 |
| `notify-permission` | string | `antiad.notify` | 命中通报发给拥有该权限的在线玩家；留空 = 只写控制台 |
| `bypass-permission` | string | `antiad.bypass` | 拥有该权限的玩家完全跳过检查，留空 = 不启用绕过 |

## trigger：命中累计与封禁阈值

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `hits` | int | `3` | 窗口内累计到第几次封禁。实际阈值会被行为分类压低（重点关注 2、广告号 1） |
| `window-seconds` | int | `60` | 累计窗口（秒），过期记录自动失效 |

## punish：处罚

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `ban-seconds` | long | `0` | `0` = 永久封禁；其他为秒数（`86400` = 一天）。IP 与账号同一时长 |
| `mode` | string | `plugin` | **封禁方式**：`plugin` = 用插件自带封禁（写 `banned-ips.json` + `banned-players.json`）；`command` = 执行你自己的封禁指令 |
| `ban-command` | string | `ban {player} {reason}` | `mode: command` 时执行的指令（不含斜杠）。占位符：`{player}` 玩家名、`{reason}` 理由、`{seconds}` 秒数（永久 0）、`{duration}` 时长（如 `2h`，永久为空） |
| `unban-command` | string | `unban {player}` | `mode: command` 时 `/antiad unban` 执行的解封指令（占位符 `{player}`） |
| `contact` | string | `服务器交流群` | 解封联系方式，替换到 `{contact}` |
| `ban-reason` | string | `宣传其他服务器（{match}），解封请联系{contact}` | 写入 `banned-ips.json` / `banned-players.json` 的理由 |
| `kick-message` | string | `&c检测到宣传其他服务器，你的 IP 与账号已被封禁。\n&7解封请联系 {contact}` | 踢出提示，支持 `&` 颜色与 `\n` 换行 |

## storage：记录库

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 关闭后不写记录库、行为画像不落盘（累计次数仍在内存） |
| `file` | string | `antiad.db` | 数据库文件名，位于 `plugins/AntiAd/`。**改这个需重启** |
| `keep-days` | int | `30` | 命中记录与 AI 用量的保留天数（`0` = 永久）。行为画像与封禁标记不清理 |

## whitelist：自己服务器的地址

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `domains` | list | `[example.com]` | 你自己的域名，**子域名自动覆盖**（写 `example.com`，`play.example.com` 也放行）。可写 `*.example.com` / `http://example.com/` 形式 |
| `ips` | list | `[1.2.3.4]` | 逐字比对：你自己的入口 IP、**你自己的 QQ 群号**等，写进来的数字不会被当成数字 IP |

另外内置一份受信任平台表（B站、YouTube、GitHub、mcmod、Modrinth、CurseForge、MC 官方与常见论坛、网盘等，见 jar 内 `trusted-domains.txt`），这些平台的链接一律不算广告。

## veteran：老玩家（免检）判定

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `play-hours` | int | `24` | 累计游玩时长（原版统计 `PLAY_ONE_MINUTE`）需**大于**这个小时数 |
| `min-score` | int | `25` | 行为分需 **≥** 这个值 |
| `clean-hours` | int | `24` | 近这么多小时内违规次数需为 0（结构类命中只算形状，不算违规） |

三条都满足 → 免检：不检查、不扣分、不统计、不会被封。三个都设 `0` = 关闭这套判定（那就只剩强制管制期生效）。

> 用原版统计读时长，需要服务端统计功能正常（`stats`）；伪造统计的做法不在防护范围内。

## behavior：行为分类（决定检查强度）

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 关闭后所有人都按 `trigger.hits` 默认阈值处理、不做分类 |
| `default-score` | int | `20` | 新玩家基础分 |
| `normal-score` | int | `30` | **≥** 该分 → 正常：只跑规则，不再花 AI |
| `suspicious-score` | int | `19` | **≤** 该分（即低于基础分）→ 重点关注：所有带文字消息都送 AI，阈值降为 2 |
| `advertiser-score` | int | `5` | **≤** 该分（或被本插件封过）→ 广告号：阈值 1，下一次命中直接封 |
| `blocks-per-point` | int | `50` | 每破坏这么多方块 +1 分 |
| `commands-per-point` | int | `10` | 每用这么多指令 +1 分 |
| `max-activity-score` | int | `20` | 行为加分上限（在线时长只展示、不计分） |
| `ad-hit-penalty` | int | `3` | 判定为广告一次扣多少分 |
| `word-hit-penalty` | int | `1` | 敏感词命中（AI 关闭时才直接算命中）扣多少分 |

细节与四档对照表见[行为分类与老玩家](行为分类与老玩家.md)。

## structure：结构化拦截（不依赖词库与 AI）

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 结构检查总开关 |
| `max-length` | int | `120` | 消息可见字符数上限（0 = 关） |
| `min-digits` | int | `8` | 「数字过多」的最少位数 |
| `max-digit-ratio` | double | `0.5` | 数字占消息长度比例超过它才算「数字过多」（防手机号/身份证/QQ 号） |
| `max-rare-chars` | int | `2` | 生僻字（CJK 扩展 A 区与 B 区以上）超过这么多个算违规（防用生僻字规避审查） |
| `combine-messages` | int | `3` | 把最近 N 条消息拼起来再查一次地址（对抗把域名拆成多条发），`1` = 关闭 |
| `check-signs` | bool | `true` | 检查告示牌内容 |
| `check-anvil` | bool | `true` | 检查铁砧改名（物品名与 lore） |
| `check-books` | bool | `true` | 检查书与笔内容 |

结构命中是**软处理**（影子隐藏 + 通报 + 扣分），**不计入封禁次数**；地址类（含拼条、告示牌/铁砧/书）才计入。

## banned-words：敏感词（交 AI 判断）

AI 开启时：命中只作为**线索**送给 AI，由 AI 决定是不是广告；AI 未启用时：命中即只给发送者看。

- 匹配前先归一化：大小写、全角、字间空格都不敏感。改成空列表 `[]` = 关闭。
- 默认列表是高精度引流词（联系方式谐音、地址词、明确的其他服名字、账号交易），日常高频词放在 `ai.trigger-words` 里当预筛。

## ai：AI 审核（可选，可完全关闭）

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关 |
| `url` | string | 智谱 GLM-4-Flash 地址 | 任意 OpenAI 兼容 `chat/completions` 地址（也可本地 Ollama） |
| `api-key` | string | 空 | **留空等于没开 AI**（此时不发任何请求） |
| `model` | string | `glm-4-flash` | 模型名 |
| `timeout-seconds` | int | `2` | 单次请求超时；DeepSeek 这类首字延迟 1~3 秒的服务建议 4~6 |
| `max-concurrent` | int | `3` | AI 线程数，**需重启生效**；免费额度有 QPS 限制时调小 |
| `price.input` / `price.output` | double | `2.0` / `8.0` | 元 / 百万 tokens，只用于 `/antiad cost` 的费用估算 |
| `trigger-words` | list | 约 40 个中信号词 | 预筛：命中这些词（或含链接样式）才送 AI；写 `[]` = 所有带文字消息都送（最贵、最不易漏） |
| `context-messages` | int | `5` | 送给模型的该玩家最近发言条数（调小省输入 tokens） |
| `fail-open` | bool | `true` | 超时/限流/报错时是否放行（`false` = 当作广告处理） |
| `refire-approved` | bool | `false` | 判定通过后：`false` = 由本插件按原版格式补发；`true` = 重新合成一次聊天事件，交给聊天插件（TrChat 这类）按它的格式广播 |
| `prompt` | string | 见配置 | 提示词，支持占位符（见下） |

## 占位符

| 占位符 | 用于 | 含义 |
|---|---|---|
| `{match}` | `punish.ban-reason` | 命中的地址 |
| `{contact}` | `punish.ban-reason` / `kick-message` | `punish.contact` |
| `{self}` | `ai.prompt` | `whitelist.domains` 里的域名列表 |
| `{minutes}` | `ai.prompt` | 该玩家进服分钟数 |
| `{hits}` | `ai.prompt` | 本窗口内已命中次数 |
| `{words}` | `ai.prompt` | 命中的敏感词/预筛词线索 |
| `{context}` | `ai.prompt` | 该玩家最近发言 |
| `{message}` | `ai.prompt` | 本次消息 |

## tlds：域名后缀表（一般不用写）

不写这一项 = 使用内置的 379 个服务器常用后缀（全部两字母国别后缀 + 常见通用后缀，含 `ren`/`icu`/`wang`；品牌后缀与 `zip`/`mov` 这类文件扩展名不收）。想自己控制就写成列表，例如 `tlds: [com, cn, net, ren]`；写 `tlds: []` = 只检测 IP，不检测域名。

## 三套推荐配置

**省心（默认）**：只跑规则 + 预筛后送 AI，命中先隐藏，60 秒 3 次才封。

**省钱**：把 AI 关掉，只留结构化拦截。
```yaml
ai:
  enabled: false
banned-words: [卖号, 代练]
```

**严格**：新玩家窗口拉长 + 预筛全开 + 阈值降低。
```yaml
settings:
  new-player-minutes: 120
ai:
  trigger-words: []        # 所有带文字消息都送 AI
trigger:
  hits: 2
```
