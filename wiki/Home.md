# AntiAd Wiki

针对 **Paper / Purpur / Folia 26.2+** 的服务器广告与违规内容管制插件。核心思路：**只管受管制的玩家**，命中不删消息、只让发送者自己看见，管理员能查、能复盘、能封。

## 一句话上手

```bash
# 1. 丢进 plugins/，启动一次服务器
# 2. 编辑 plugins/AntiAd/config.yml（至少要改 whitelist 和 punish.contact）
# 3. 生效
/antiad reload
# 4. 自检
/antiad test 来玩 mc.example.com:25565   # 规则试跑
/antiad check <玩家名>                   # 看某人是否在管制范围
```

## 设计原则

1. **不删消息**：取消原版事件并只把内容补回给发送者，发送者看不出被拦（也顺带解决聊天格式化插件抢广播的问题）。
2. **不碰老玩家**：不检查、不计分、不统计、不会被封。
3. **确定性规则优先**：地址结构、结构异常、跨消息拼接都不花钱、不联网，AI 只作最后一道语义补充。
4. **误伤优先于漏判**：AI 超时/报错一律放行；分类越可疑才越严格。
5. **可查可复盘**：每次命中写库（原文、命中内容、处理结果），每次 AI 判定写后台日志。

## 版本与依赖

- 服务端：Paper / Purpur / Folia 26.2+（`api-version: 26.2`、`folia-supported: true`），实测 Purpur 26.3-2642 与 Folia 26.2-7。
- Java：25（编译目标 25）。
- 数据库：内置 sqlite-jdbc（随包分发，Apache-2.0）。
- 统计：内置 bStats（插件 ID 34706，可全局关闭）。
- 不依赖 Vault / PlaceholderAPI / ProtocolLib。
