# 记录与查询

所有记录都在 `plugins/AntiAd/antiad.db`（SQLite）。默认保留最近 30 天（`storage.keep-days`）。

## 三张表

| 表 | 内容 | 清理策略 |
|---|---|---|
| `hits` | 每次命中：时间、玩家 UUID/名字、IP、类型、命中内容、整条原文、处理结果（`hidden`/`banned`） | 按 `keep-days` 清理 |
| `usage` | AI 用量按天累计：调用次数、输入/输出 tokens | 按 `keep-days` 清理 |
| `behavior` | 行为画像：方块/在线分钟/指令/进服次数、扣分、是否被封过（永久标记） | **不清理** |

`hits` 的 `kind` 取值与含义：

| kind | 含义 | 是否计入封禁次数 |
|---|---|---|
| `ad` | 地址规则命中（IPv4 / 数字 IP / 域名） | ✅（**但要看下方 `action`**） |
| `ai` | AI 判定为广告 | ✅ |
| `combine` | 跨消息拼条命中 | ✅ |
| `sign` / `anvil` / `book` | 告示牌 / 铁砧改名 / 书与笔命中 | ✅ |
| `word` | 敏感词命中（AI 关闭时的直接隐藏） | ❌ |
| `structure` | 结构异常（超长 / 数字过多 / 生僻字过多） | ❌ |
| `ban` | 封禁动作本身 | ✅（同时是封禁记录） |

`action` 字段表示这次怎么处置的：

| action | 含义 | 计入封禁次数 |
|---|---|---|
| `hidden` | 隐身处理：只给发送者自己看见 | ✅ |
| `banned` | 已封禁（IP + 账号） | ✅（record 本身） |
| `released` | 地址命中但**不是 MC 服务器**（域名不存在 / 只是网站 / 屏蔽了探测）→ 聊天消息照原样放行，不扣分 | ❌ |
| `soft` | 同上，但入口是告示牌/铁砧/书/命令（没法只重放给本人）→ 只隐藏 + 通报 + 轻度扣分 | ❌ |

## 查询

| 命令 | 看什么 |
|---|---|
| `/antiad records [玩家]` | 最近 10 条命中记录（含隐藏的原文与 AI 理由） |
| `/antiad check <玩家>` | 某人的累计命中条数、封禁次数、行为分与分类 |
| `/antiad cost` | AI 用量与费用估算（近 7 天逐日 + 近 30 天 + 建库以来） |
| `/antiad behavior [数量]` | 行为画像列表 |

想直接查库（推荐只读打开，避免和服务器抢锁）：

```bash
sqlite3 plugins/AntiAd/antiad.db "select datetime(hit/1000,'unixepoch','localtime'), player, ip, kind, match, content from hits order by hit desc limit 20;"
```

## 重启后的连续性

- **累计次数**：`trigger.window-seconds` 窗口内的命中次数会从 `hits` 表恢复，重启不会清零。
- **行为画像**：从 `behavior` 表恢复（含"是否被封过"的永久标记）。
- **AI 用量**：按天累计在 `usage`，重启不影响。

## 备份与并发

- 写入全部在**异步线程**、且使用**批量事务**（每分钟一次），命中记录即时异步写入 —— 不会卡服务端线程。
- 用 DriveBackupV2 这类插件备份时，如果它锁住了数据库文件，写入会**排队等待**（不影响服务器运行，只是记录晚一点落盘）。
- **不要**在服务器运行时直接复制 `antiad.db` 当作备份（可能拿到不一致的快照）。要备份就：停服复制，或用支持 SQLite 的备份工具（`VACUUM INTO` / `sqlite3 .backup`）。

## 清理与体积

- 默认 30 天清理一次 `hits` + `usage`（清理在启动时、以及数据库连续运行时的定时任务里做）。
- `behavior` 表一人一行，长期占用很小；如果服务器来客极多（几十万不同玩家），可以定期手工 `delete from behavior where updated < ...`（会同时清掉行为画像，老玩家判定会重新从基础分算起）。
- 想永久保留记录：`storage.keep-days: 0`。

## 隐私

记录库内容**只在本机**，不会上传。AI 审核时才把聊天内容发给**你自己配置的**接口（不含玩家名/UUID/IP），详见 [AI 审核](AI审核.md) 的隐私一节。bStats 只上报插件/服务端/环境类信息，可在 `plugins/bStats/config.yml` 全局关闭。
