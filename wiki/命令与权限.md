# 命令与权限

主命令 `/antiad`，别名 `/adban`。所有子命令支持 Tab 补全（子命令名、在线玩家名）。

## 玩家/管理员命令

### `/antiad check <玩家>`

查看某人**是否在管制范围**与当前状态。支持在线玩家和本服缓存过的离线玩家。

```
/antiad check Steve
Steve （在线）进服已 0 分钟
老玩家判定：累计 0.0 小时（需 > 24）、行为分 20 （需 ≥ 25）、近 24 小时违规 0 次（需 0）→ 受管制
当前状态：受管制（按行为分类决定检查强度）；已命中 0/3 次
记录库：共 0 条，其中封禁 0 次。
行为分 20 （观望，累计：方块 0 / 在线 0m / 指令 0 / 进服 1；该类封禁阈值 3）
IP：127.0.0.1；账号封禁：否；IP 封禁：否
AI 审核：已开启（glm-4-flash）
```

### `/antiad ban <玩家> [时长] [理由…]`

手动封禁 **IP 与账号**（和自动封禁同一套逻辑）。

- 时长：`30s` / `10m` / `2h` / `7d`，纯数字 = 秒，留空或 `0` = 永久。
- 理由：可写中文；不写就用 `punish.ban-reason`（把 `{match}` 换成"管理员手动封禁"）。
- 效果：写封禁名单（IP + 账号）、在线时踢出并显示 `punish.kick-message`、写一条 `hits` 记录（类型 `封禁`）、把该玩家**永久标记为广告号**（以后阈值 1）、通报有 `antiad.notify` 的人。
- 离线玩家也能封：优先用它在线的 IP，否则用记录库（`hits`）里最近一次记录的 IP；都没有就只封账号。

```
/antiad ban Steve 2h 在聊天里发别的服地址
已封禁 Steve（账号 + IP，时长：7200 秒）

/antiad ban Alex
已封禁 Alex（账号 + IP，时长：永久）
```

### `/antiad unban <玩家>`

解封账号，并把该玩家最近记录里的 IP 一并解封（这两样都是自动封禁会一起写的）。

```
/antiad unban Steve
已解封 Steve 及其最近 IP 203.0.113.9
```

如果记录里没有 IP（比如从没被记录过），只解账号，并提示你用原版 `/pardon-ip <地址>`。

### `/antiad behavior [数量]`

按最近活跃列出行为画像（默认 10 条，最多 50）。

```
/antiad behavior 5
行为画像（按行为累计：挖方块/指令加分，违规扣分）：
Steve 观望 行为分 21（方块 53 / 在线 3m / 指令 11 / 进服 1 / 扣分 0）
```

### `/antiad ai <文本>`

**真的**调用一次 AI（用当前配置），回报判定、理由、耗时；接口/Key 有问题直接显示错误。用于验证 key 是否可用、模型判得准不准。不处罚、不写记录。

```
/antiad ai 快来玩别的服 mc.other.top
正在请求 glm-4-flash (https://open.bigmodel.cn/api/paas/v4/chat/completions)…
判定：是广告（理由：发了别的服地址；耗时 412ms；会按命中累计）
```

### `/antiad cost`

每日 AI 调用次数与估算费用（按 `ai.price` 的单价算）。

```
AI 费用估算 （单价：输入 2.0 / 输出 8.0 元每百万 tokens，可在 ai.price 调整）
2026-10-16 今天 调用 128 次 | 输入 58200/输出 3400 tokens | 约 ¥0.1436
近 7 天：1580 次，约 ¥1.7200；近 30 天：4200 次，约 ¥4.5500
建库以来：9000 次，约 ¥9.8000（统计到 30 天前，keep-days=0 时永久保留）
```

### `/antiad records [玩家]`

最近 10 条命中记录（含隐藏的原文与 AI 判定理由）。

```
/antiad records
最近 4 条命中记录：
10-16 12:01 封禁   Steve 203.0.113.9 已封禁 命中 mc.example.net ：来玩我的服 mc.example.net
10-16 12:01 拼条   Steve 203.0.113.9 已隐藏 命中 mc.example.net ：.net 挺好玩的
10-16 12:01 结构   Steve 203.0.113.9 已隐藏 命中 消息过长（260 字符） ：这是一条很长的…
10-16 12:00 告示牌 Steve 203.0.113.9 已隐藏 命中 mc.other.ren ：来玩我的服 mc.other.ren
```

类型标签：`广告` / `AI` / `敏感词` / `拼条` / `结构` / `告示牌` / `铁砧` / `书` / `封禁`。

### `/antiad test <文本>`

**只试跑规则**，不处理、不记录、不调 AI。输出归一化结果、地址命中、敏感词命中，以及"这条消息按现在的配置会不会被送进 AI"：

```
/antiad test 来玩 play.example.com
归一化：来玩 play.example.com
规则未命中。该消息实际会被送给 AI 审核。

/antiad test 来玩 mc.other.top
归一化：来玩 mc.other.top
广告命中：mc.other.top（累计 3 次 / 60 秒封禁 IP 与账号）

/antiad test 看看这个 www.bilibili.com/video/BV1xx
归一化：看看这个 www.bilibili.com/video/bv1xx
规则未命中。也不像广告（无关键词、无链接）：不会送 AI，省额度。

/antiad test 123
归一化：123
规则未命中；纯数字/符号，不会送 AI。
```

### `/antiad reload`

重载配置（同时会做[配置自动补全](安装与升级.md)）。`storage.file` 与 `ai.max-concurrent` 需要重启才生效。

### `/antiad help`

打印命令列表。

## 解封（用原版命令）

```
/pardon-ip 203.0.113.9        # 解封 IP
/pardon Steve                 # 解封账号
```

封禁名单就是服务端原生的 `banned-ips.json` / `banned-players.json`。

## 权限

| 节点 | 默认 | 说明 |
|---|---|---|
| `antiad.admin` | op | 使用 `/antiad` 全部子命令 |
| `antiad.notify` | op | 接收命中与封禁通报（聊天栏 + 控制台始终有日志） |
| `antiad.bypass` | op | 完全跳过检查（管理员在自己服务器里发地址不会被处理）；权限名可用 `settings.bypass-permission` 改，留空 = 不启用 |
