# 安装与升级

## 环境要求

| 项 | 要求 |
|---|---|
| 服务端 | Paper / Purpur / Folia **26.2 或更新**（插件用 `api-version: 26.2` 构建，可跑在 26.3） |
| Java | **25**（插件按 Java 25 编译） |
| 可选 | 装了接管聊天的插件（TrChat 等）也兼容，见[兼容与 Folia](兼容与Folia.md) |
| 不需要 | Vault、经济插件、PlaceholderAPI、ProtocolLib |

## 安装

1. 把 `AntiAd-1.0.2.jar`（约 110 KB）放进服务器 `plugins/` 目录。
2. 启动服务器（或 `/reload`）。首次启动会创建 `plugins/AntiAd/config.yml` 与 `plugins/AntiAd/antiad.db`，并从**阿里云镜像**下载 SQLite 驱动到服务端根目录的 `libraries/org/xerial/sqlite-jdbc/3.51.0.0/`（见下节）。
3. 编辑配置：**至少**要改这两项，否则会误伤或找不到解封入口。
   ```yaml
   whitelist:
     domains: [your-server.com]        # 你自己的域名（子域名自动覆盖）
     ips: [203.0.113.10]               # 你自己的入口 IP / QQ 群号等
   punish:
     contact: 'QQ 群 123456'           # 封禁理由/踢出提示里的解封联系方式
   ```
4. 生效：`/antiad reload`。
5. 自检：
   - `/antiad test 来玩 mc.example.com:25565` → 应显示「广告命中：mc.example.com」
   - `/antiad test 看这个 www.bilibili.com/video/BV1xx` → 应显示「规则未命中」（受信任平台）
   - 想验证 AI：`/antiad ai 快来玩别的服 mc.other.top`

## 首次启动会下载 SQLite 驱动（走国内镜像）

SQLite 驱动（`sqlite-jdbc`，含全平台原生库，约 13MB）**没有打进 jar**，否则插件本体就要 12MB。它由插件自带的 Paper 加载器 `AntiAdLoader` 在首次启动时拉取：

```yaml
paper-plugin-loader: cn.server.antiad.AntiAdLoader
paper-skip-libraries: true          # 驱动由上面的加载器负责，老的 libraries 机制不再重复解析
libraries:                          # 兜底：万一服务端不认 paper-plugin-loader
  - org.xerial:sqlite-jdbc:3.51.0.0
```

加载器的仓库顺序（**优先国内源，不用等官方源**）：

1. 服务端自己配的镜像 —— 启动参数 `-Dorg.bukkit.plugin.java.LibraryLoader.centralURL=…` 或环境变量 `PAPER_DEFAULT_CENTRAL_REPOSITORY`
2. **阿里云公共仓库**（默认）：`https://maven.aliyun.com/repository/public`
3. Paper 官方镜像（只有阿里云不可用时才走）

下载结果缓存在服务端根目录的 `libraries/org/xerial/sqlite-jdbc/3.51.0.0/`，之后不再联网（仓库 id 与官方一致，所以同一台机器上别的插件下过的同一版本会被直接复用，不会重复下载）。日志里能看到：

```
[MavenLibraryResolver] Downloading https://maven.aliyun.com/repository/public/org/xerial/sqlite-jdbc/3.51.0.0/sqlite-jdbc-3.51.0.0.jar
[SpigotLibraryLoader] [AntiAd] Loaded library ...\libraries\org\xerial\sqlite-jdbc\3.51.0.0\sqlite-jdbc-3.51.0.0.jar
```

- **服务器没有外网 / 想离线装**：从阿里云直接下 `https://maven.aliyun.com/repository/public/org/xerial/sqlite-jdbc/3.51.0.0/sqlite-jdbc-3.51.0.0.jar`，放进 `<服务端根目录>/libraries/org/xerial/sqlite-jdbc/3.51.0.0/` 再启动即可（文件名必须一致）。
- 下载失败时插件仍会加载，只是记录库不可用（日志里会有 `无法打开记录库`），广告检查照常工作。
- 想给**所有插件**统一换源（不只是 AntiAd）：在启动脚本里加
  `-Dorg.bukkit.plugin.java.LibraryLoader.centralURL=https://maven.aliyun.com/repository/public`
  或设环境变量 `PAPER_DEFAULT_CENTRAL_REPOSITORY`。

## 文件布局

```
plugins/AntiAd/
├── config.yml                     # 配置（可自动补全，改前会备份）
├── config.yml.bak-20261016-120000 # 配置自动补全前的备份
└── antiad.db                      # SQLite：命中记录 / AI 用量 / 行为画像
libraries/org/xerial/sqlite-jdbc/  # 服务端自动下载的 SQLite 驱动（不在插件目录里）
plugins/bStats/config.yml          # bStats 全局统计开关（可选关掉）
```

## 升级

1. 覆盖 `plugins/AntiAd-1.0.2.jar` 为新版。
2. 重启（**推荐**）或 `/plugman reload AntiAd`（装了 PlugManX 的话）。
3. 执行 `/antiad reload`。

**配置会自动补全**：新版新增的配置项会在启动/重载时自动写进你的 `config.yml`（**注释一起带过来**），并且**不覆盖你已改过的值和你自己写的注释**。补全前会把原文件备份成 `config.yml.bak-yyyyMMdd-HHmmss`，日志里会列出补了哪些项：

```
[AntiAd] 配置自动补全 45 项：settings.check-numeric-ip、…、veteran.play-hours、ai.price.input（原文件已备份为 config.yml.bak-20261016-092328）
```

注意：被**删除**的旧配置项不会从你的文件里移除（留着不生效，避免动你的文件）。保存配置时文件会被规范化重写（行内列表变成块状、引号可能被去掉），键值不变，可用备份回滚。

## 卸载

1. 停服，删除 `plugins/AntiAd-1.0.2.jar`。
2. 想清数据就删 `plugins/AntiAd/`（`antiad.db` 里有命中记录与行为画像）。
3. **插件封过的 IP 与账号不会自动解封**，它们在服务端原生的 `banned-ips.json` / `banned-players.json` 里，需要 `/pardon-ip <地址>` 与 `/pardon <玩家名>`。

## 回滚到旧版

直接换回旧 jar 即可；如果新版把配置项改名了，旧版会忽略不认识的项（可能行为不同，建议同时用 `config.yml.bak-*` 恢复一份与新版本匹配的配置）。
