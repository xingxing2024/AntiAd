# AI 审核

AI 是可选的**语义补充层**：确定性规则（地址/结构/拼条）管不住的、不带地址的软广告，交给模型判断。默认配置指向智谱 GLM-4-Flash，**不填 `api-key` 就等于没开**（一个请求都不发）。

## 一、接入

任意 **OpenAI 兼容**的 `chat/completions` 都能用：

| 服务 | `url` | `model` | 备注 |
|---|---|---|---|
| 智谱 GLM-4-Flash | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4-flash` | 默认，官方标称免费 |
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` | `deepseek-chat` | 按量付费；首字延迟 1~3 秒，`timeout-seconds` 建议 4~6 |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `Qwen/Qwen2.5-7B-Instruct` | 有免费小模型 |
| OpenRouter | `https://openrouter.ai/api/v1/chat/completions` | `meta-llama/llama-3.1-8b-instruct:free` | 带 `:free` 的模型免费 |
| 本地 Ollama | `http://127.0.0.1:11434/v1/chat/completions` | `qwen2.5:7b` | 完全免费离线，`api-key` 随便填非空 |

配置好后用 **`/antiad ai <文本>`** 验证：它会真的发一次请求，回报判定、理由、耗时，或直接告诉你错在哪（`HTTP 401` = key 不对，`429` = 限流，`无法解析` = 模型没按 JSON 回，`调用失败` = 网络/超时）。

## 二、什么时候会调用 AI

1. 该玩家**受管制**（老玩家不送）。
2. 规则（地址/结构/拼条）**没有命中**。
3. 满足以下之一：
   - 消息命中 `ai.trigger-words` 里的词；或
   - 消息含**链接样式**（`http`、`www.`、`@`、任意点号域名，不管后缀认不认识）；或
   - 该玩家分类是**重点关注/广告号**（此时不看预筛，所有带文字消息都送）；或
   - 命中了 `banned-words`（敏感词一定送，并把命中的词作为线索）。
4. 消息里**有文字**（纯数字、表情、标点不送）。

纯数字、表情、标点，以及"正常"分类玩家的消息，都不会消耗 AI 额度。

## 三、判定流程与表现

- 消息会先被**扣住**（发送者也暂时看不到），等模型结论（最多 `timeout-seconds` 秒）。
- 判定**是广告** → 只回给发送者（其他玩家看不到）、按命中累计、扣行为分。
- 判定**不是广告** → 原样放行：
  - `refire-approved: false`（默认）：由本插件按原版格式补发给原观众（任何服务器都能用，但没有聊天插件的前缀/颜色）。
  - `refire-approved: true`：交给聊天插件（TrChat 这类）重新广播一遍，保留它的格式（**要求服务器确实装了这类插件，否则消息会丢**）。
  - ⚠ **装了 TrChat 这类接管聊天的插件时必须用 `true`**：它们会取消聊天事件、自己按频道广播，`false` 时本插件补发的消息不经过它，玩家会看到没有 TrChat 格式（或干脆看不到）的裸消息。
- 超时/限流/报错 → 按 `fail-open` 处理（默认放行，规则仍然兜底）。

## 四、提示词

`ai.prompt` 可自由修改，支持占位符：

| 占位符 | 含义 |
|---|---|
| `{self}` | `whitelist.domains` 里的域名（告诉模型本服地址，避免把"提本服"当广告） |
| `{minutes}` | 该玩家进服分钟数 |
| `{hits}` | 本窗口内已命中次数 |
| `{words}` | 命中的敏感词/预筛词线索（只是线索） |
| `{probe}` | **地址情报**：对消息里出现的地址做技术探测的结论（见[判定流程](判定流程.md)的地址情报一节），例如「mc.example.com：25565 端口回应了 Minecraft 状态（版本 1.20.1，在线 3/20）」。**提示词里没写 `{probe}` 时，插件会把这一行自动附在末尾**（老配置升级后不用改也能生效；想自定义位置就自己加上占位符） |
| `{context}` | 该玩家最近 `context-messages` 条发言 |
| `{message}` | 本次消息 |

模型必须回**一行 JSON**：`{"ad":true或false,"reason":"一句话理由"}`。解析时按这个形状找（`"ad":` 后必须跟 `true`/`false` 且以 `,` 或 `}` 结束，所以模型照抄提示词里的示例不会被误判）。

调优建议：

- **误判成广告**：在提示词里补"××不算广告"，并把该域名/关键词加进 `whitelist`；也可以把 `{words}` 那行的措辞改得更"保守"。
- **漏判**：把 `ai.trigger-words` 设成 `[]`（全量送 AI），或把容易漏的词加进 `banned-words`。
- 拿不准就**先调提示词**，再考虑换模型。

## 五、成本控制

| 手段 | 做法 |
|---|---|
| 只送可疑消息 | 保持 `ai.trigger-words` 有内容（默认就是），别设 `[]` |
| 少送上下文 | `ai.context-messages: 2`（省 50~150 输入 tokens/次） |
| 缩短提示词 | 精简 `ai.prompt`（提示词本身占单次输入的大头） |
| 缩小范围 | 调小 `settings.new-player-minutes`，或提高 `veteran.play-hours` 让更多人免检 |
| 分级放行 | 保持 `behavior` 开启：正常玩家（≥30 分）完全不调 AI |
| 关掉 AI | `ai.enabled: false`（回到纯规则模式） |
| 看花了多少钱 | `/antiad cost`（按 `ai.price` 估算近 7 天/30 天/累计） |

单次调用大致是「提示词 + 最近几条上下文 + 本次消息」几百 tokens 输入 + 二三十 tokens 输出。DeepSeek 常见档位下约 **¥0.001/次**；具体以你用的服务价目为准。

## 六、隐私

- 会发送：**聊天原文**、该玩家最近几条发言（上下文）、进服分钟数、本窗口命中次数。
- 不会发送：玩家名、UUID、IP（除非玩家自己把名字写进消息里）。
- 记录库（`antiad.db`）里的内容**只留在你服务器本地**，不会上传。
- 官方之外的服务商（含本地 Ollama）都有自己的隐私策略/数据留存方式，请自行确认合规。

## 七、可观测性

每次 AI 判定（**包括判为"不是广告"**）都会写一行后台日志，方便复盘模型是否在正常工作：

```
[AntiAd] AI 审核 玩家名：是广告（理由：发了别的服地址；耗时 450ms；tokens 412+18；线索：加群）消息：快来玩别的服 进服送VIP mc.other.ren …
[AntiAd] AI 审核 玩家名：不是广告（理由：普通聊天；耗时 380ms；tokens 390+16；线索：链接样式）消息：看看这个 www.bilibili.com/…
[AntiAd] AI 审核返回 HTTP 401
```

配合 `/antiad records`（记录块里类型显示 `AI`，附模型给的理由）和 `/antiad cost`（用量与费用），能很快定位是"模型判错"还是"规则判错"。
